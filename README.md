Closet design game allowing the user to draw clothing from templates, using tool brush and cut and paste style applications. Each user will be able to choose their mannequin from a set of male/female characters with several different body types. Templates will be provided based on the user's preference of region and era. Upon selection, we will provide different clothing templates based on said region and era for the user to customize as they see fit. Users will be able to save the outfit to a collection, and share on external social media feeds.
